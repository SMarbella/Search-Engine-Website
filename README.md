# Search Engine Website
## Summary
The **Search Engine Website** provides visitors search results through an AI model and acts as a mock search engine website. Each page includes a mock support section, FAQ (frequently asked questions), settings, website updates, terms of service, privacy policies, and user settings.

This website project is created with BlueGriffon. It does not use Drupal or Wordpress. This project is a search engine website that pulls query results based on the user's queries using the GPT-4o mini AI model. I trained a GPT-4o mini AI model to have a self-assured personality. I first started it in 2018 on Wordpress as a fan-made website based on a Disney search engine character who appeared in Ralph Breaks the Internet. In 2025, I recreated the website from scratch using HTML and CSS. I constructed the site logo and designs based on movie screenshots to capture the details. Although the movie only shows the main page, I created the other site pages based on my imagination to portray how the other pages would have looked like.

The Internet is a large web of databases interconnected with one another. Search engines are integral to web browsing, querying through data and information to find search results relevant to a user's query. I wanted to experiment with AI and collect observations between human and computer interactions. I wanted to observe how well AI-powered search engines pull search results compared to traditional search engines.
