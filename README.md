# Search Engine Website
## Summary
[![Welcome to KnowsMore!](https://github.com/SMarbella/Search-Engine-Website/blob/site/screenshots/Home%20Page.png)](https://smarbella.github.io/Search-Engine-Website/index.html)

The **Search Engine Website** project is created with BlueGriffon. It does not use Drupal or Wordpress. Using natural language processing, neural networks, and GEO (Generative Engine Optimization), the AI searches through a large database (publicly available information on the Internet) and pulls results based on user's search queries. It uses the GPT-4o mini AI model. I trained a GPT-4o mini AI model to have a self-assured personality. I first started the project in 2018 on Wordpress as a fan-made website based on a Disney search engine character, KnowsMore, who appeared in Disney's 2018 movie, Ralph Breaks the Internet. KnowsMore, who resembles a small purple professor, is an AI agent and search engine, providing users detailed results to search queries. His style and way of interaction (natural language processing and neural networks) pays homage to Ask Jeeves and old search engines. He interacts with users the same way as AI, making the website ahead of its time in 2018. In 2025, I recreated the website from scratch using HTML and CSS. I constructed the site logo and designs based on movie screenshots to capture the details. Although the movie only shows the home page during the scenes that feature KnowsMore, I created the other site pages based on my imagination, programming experience, and artistic skills to portray how the other pages would have looked like.

The Internet is a large web of databases interconnected with one another. Search engines are integral to web browsing and querying through data and information to find search results relevant to a user's query. KnowsMore provides visitors search results through an AI model and acts as a mock search engine website. This project to recreate a website from a movie interests me because it is an interesting concept to bring an AI-powered search engine to life. I wanted to observe how well AI-powered search engines pull search results compared to traditional search engines. I wanted to experiment with AI and collect observations between human and computer interactions. Interacting with the AI from the KnowsMore website deepens my understanding of AI, the biases it may have, the more details it forgets/remembers (measuring memory retention per chat message sent), and amount of inaccuracies that accumulate the more the users interact with it. Each page includes a mock section and description related to their titles. The website's header includes individual pages for:
- **Home:** It is accesssed through the website's logos in the header and on the page. It includes a mock searchbar and button where users can write queries. They can ask an actual question or provide keywords in their search queries.
- **Email:** Includes the contact email of the mock company.
- **FAQ (frequently asked questions):** Includes detailed descriptions about the website's mascot, values, uses, information confidentiality, and a list of recommended sites.
- **Accounts:** A set of mock social media handles of the company, showing the company's presence in other sites.
- **Update:** Company updates about the search engine tool. It is also an archive of the changes that happens to the mock website's company.
- **What's New?:** The latest news or a list of feedbacks from users on ways to improve the website and how the mock company listens to feedback or welcomes room for improvement.

The footer includes:
- **Privacy:** A basic privacy policy explaining how the mock website deals with data.
- **Terms:** This page explains the terms of service and list of rules the user may agree upon.
- **settings:** A simple mock settings page.

## Website Features

The following REQUIRED features are completed:
- [x] HTML code used to build the blueprint of the website
- [x] Used HTML to give the website a title, pages, and bodies of texts
- [x] CSS used to create visuals and added images to each website page
- [x] Use React.js to automatically resize the website to browser size or screen size

The following FUNCTIONALITY features are implemented:
- [x] Multiple pages in one website
- [x] An interactive menu that leads users to different pages

The following EXTRA features are implemented:
- [x] Added an interactive searchbar
- [x] Enhanced website decoration to match the theme of the subject
- [x] Embedded a repeating question mark (?) background to give the visitor a feel of curiosity and knowledge
- [x] Compatible with both desktop computers and mobile devices
- [x] Compatible with both Android and iOS devices
- [x] Menu buttons add an underline mouse hovers over them
- [x] User-friendliness is enhanced by telling the visitor which page they are on by showing the title in the header and the title's button a different color

## Notes
This website shows my creative and artistic side in web development. I demonstrated my artistic talent through the decorations used to make the website visually appealing. The borders, titles, and website design came from my imagination to help visitors feel immersed in the scholarly search engine world. While designing the fan art for the website, I wanted to preserve the movie's aesthetics to enhance the look and feel of the search engine website. All pages, except for the search bar page, were not visible in the movie. They were created from scratch, expanding on how the search engine website would have looked if it was a real website.
